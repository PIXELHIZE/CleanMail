# 일회용 이메일 실서비스 조사 — 2026-08-18

이 문서는 CleanMail의 수동 검증 계층과 회전형 도메인 탐지를 만든 당시의 재현 가능한 조사 기록이다. Google·Naver와 일본어 검색, 운영 사이트, 블로그·커뮤니티, 공개 공급자 연관 페이지를 교차 확인했다. 서비스가 직접 발급하거나 선택기에 표시한 값은 최우선 증거로 사용했고, 회전이 빠른 공급자는 현재 도메인 표본과 전용 MX 인프라를 함께 확인했다.

## 채택 기준

- `issued`: 서비스가 현재 생성한 주소의 `@` 뒤 도메인
- `selector`: 서비스의 도메인 선택기에 현재 표시된 도메인
- `public API`: 서비스가 현재 활성 상태로 반환한 도메인
- `provider correlation`: 현재 임시메일 공급자 페이지와 MX가 함께 연결한 도메인
- `MX fingerprint`: 여러 회전 도메인이 공통으로 사용하는 전용 메일 서버 호스트 또는 IP
- 정상 메일 사업자 도메인은 일회용 주소에 쓰였더라도 전체 차단하지 않음

초기 조사, 후속 실사용 표본, 한국·일본 집중 조사에서 채택한 111개 도메인과 근거는 [`verified_evidence.json`](../src/cleanmail/data/verified_evidence.json)에 있다. 회전형 서비스용 25개 MX 호스트 접미사와 13개 수신 IP는 각각 [`mx_patterns.txt`](../src/cleanmail/data/mx_patterns.txt), [`mx_ips.txt`](../src/cleanmail/data/mx_ips.txt)에 있다.

## 후속 실사용 표본 추가

사용 과정에서 일회용 주소임이 확인됐지만 기존 목록에서 누락된 다음 6개 고유 도메인을 별도 허용 계층 없이 기존 `verified` 차단 계층에 직접 편입했다.

- `tempmail.freevpnplanet.com`
- `temp-email.io`
- `beaconwarp.com`
- `mailingdragon.com`
- `imnmail.com`
- `temp-mail.snaper24.com`

서브도메인으로 제공된 주소는 `freevpnplanet.com`이나 `snaper24.com` 전체가 아니라 실제 메일 주소에 쓰인 서브도메인만 차단한다.

## 회전형 도메인 대응

YOPmail과 CleanTempMail처럼 수십~수천 개의 도메인을 짧은 주기로 바꾸는 서비스는 정적 복사만으로 따라가기 어렵다. 따라서 온라인 검사에서 주소 도메인의 MX를 조회한 뒤 다음 전용 인프라를 접미사 또는 IP로 판별한다.

- YOPmail, GuerrillaMail, Mailinator, CleanTempMail
- kuku.lu/InstAddr, mail.cx, mail.tm
- Temp-Mail.org 계열 수신기, TempMailbox/CrazyMailing
- generator.email, emailfake 계열, tmailor, tempm

공용 Cloudflare Email Routing, Google, Hostinger MX 자체는 지문으로 넣지 않았다. 이런 공용 인프라 전체를 차단하면 정상 개인·기업 도메인이 대량으로 오탐된다.

## 조사했지만 수동 채택하지 않은 사례

| 서비스/후보 | 처리 | 이유 |
|---|---|---|
| Emailnator | 제외 | 일회용 주소가 `gmail.com`을 사용하므로 Gmail 전체 차단은 심각한 오탐을 만든다. `gmail.com`은 허용 목록으로 보호한다. |
| tempmailg.com | 보류 | 조사 시점에 주소 초기화가 끝나지 않아 발급 도메인을 확인하지 못했다. |
| Easy Ten Mail | 보류 | 한국 임시메일 서비스 소개는 확인했지만 실제 발급 도메인은 확인하지 못했다. |
| ruu.kr | 제외 | 서비스 종료 안내가 표시됐다. |

## 기준 목록 비교

검증 표본에 대한 두 기준 저장소의 포함 여부는 [`baseline_comparison.json`](../src/cleanmail/data/baseline_comparison.json)에 저장한다. 현재 111개 표본에서 `disposable-email-domains`는 12개, `groundcat`은 5개, 둘의 합집합은 14개를 탐지했다. 이 수치는 의도적으로 최신 누락값을 많이 포함한 표본 평가이며 전체 인터넷에 대한 재현율로 해석하면 안 된다.
